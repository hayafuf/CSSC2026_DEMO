■ 読者の想定
--------------------------------------------------------------------------------
・プログラミング初心者。JavaScript の変数・if・for・関数は「見たことがある」程度。
・オブジェクト、配列、無名関数(コールバック)は「なんとなく分かる」。
・数学は中学レベル。三角関数・ベクトル・内積は「習ったかもしれない」。
・CreateJS は完全に未経験。canvas も触ったことがない。

したがって本ドキュメントは:
・専門用語は必ずその場で定義する。「あとで説明します」を極力使わない。
・数式は必ず「この式が何をしたいのか」を日本語で先に言う。
・コードは必ず file:line 付きで実物を貼る。要約・擬似コードで済ませない。
・「なぜこう書いてあるのか」を、書かなかった場合に何が壊れるかで説明する。
  → 幸い、このコードは実測データ入りのコメントが大量にあるので、その根拠を引く。

■ 用語の統一表(章をまたいでブレさせない)
--------------------------------------------------------------------------------
  玉             ボール/ボールではなく「玉」。コード上は ball / balls。
  チェーン       レール上に並んだ玉の列全体。
  グループ       チェーンのうち、隙間なく接触している連続部分。
  レーン(lane)  「レール1本 + そのチェーン + その樽」の1組。コースは1〜N本持つ。
  コース(course) レーンの集合 + 見た目フラグ。PP.COURSES に定義がある。
  レール(rail)  1本の道の幾何。rail.create() が返すインスタンス。
  弧長 d        レール上を洞窟から測った距離(px)。玉が持つ唯一の位置情報。
  洞窟          d = 0 の地点。玉が湧く。
  樽            レールの終点。ここに玉が入るとゲームオーバーに近づく。
  波(wave)     一度にまとめて補給される玉の一団。末尾に宝玉が付く。
  宝玉          波の末尾に付く金色の玉。treasure: true を持つ。
  割り込み      発射した玉がチェーンの途中に挿入されること(insertShot)。
  磁力          隙間の前後が同色のとき、前のグループが後退して合流する現象。
  反動(recoil) 磁力の合流でぶつかったとき、後ろのグループが押し戻されること。
  レイヤー      createjs.Container。描画の重なり順(Z順序)を作る箱。
  焼き込み      .cache()。ベクタ描画を1枚の画像にしてしまうこと。
  tick          1フレーム。createjs.Ticker が呼ぶ関数。
  dt            1フレームの経過秒数。
