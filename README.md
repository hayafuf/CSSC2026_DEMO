# 🏴‍☠️ 海賊の秘宝 — チェーンシューターゲーム

同じ色の玉を3つ以上そろえて消す **チェーンシューター** パズルゲームです。
CreateJS(EaselJS + TweenJS)で実装しています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要)。

- 画面上部から**塗装された玉の列(チェーン)**がレールに沿って流れてきて、**ゴールの樽**に向かって進みます。
- 玉は**波(wave)単位**で洞窟から補給され、各波の**末尾には光る宝玉 💎** が付きます。
- 画面下の**大砲はマウスで左右にスライド移動**します(原作準拠)。**クリックで真上に発射**し、チェーンに玉が割り込みます。
- **同じ色が3個以上つながると弾けて消えます。**
- 消えた隙間の前後が同じ色なら、前の列が**磁力で巻き戻って**くっつき、連鎖(コンボ)が起きます。
- **右クリックまたは Space キー**で「今の玉」と「次の玉」を交換できます。
- 装填される色は**チェーンに残っている色**から抽選されます(盤面に無い色は出ません)。
  **樽に近い玉の色ほど出やすい**ので、手前の危機に対処しやすくなっています(最後尾側だけの色も低確率で出ます)。
- **すでに同色2個が接触している色**(= あと1個で消える色)が優先して配られます(重み ×3.5)。
  逆に「孤立した色」を優先すると、配られた玉を孤立玉の隣に付けてペアにするばかりで**仕上げの1個が来ず、
  消えないペアが盤面に溜まり続けます**(実測: 150手後に残るペアが 4色 1.6組 → 2.4組、5色 3.5組 → 4.9組に増える)。
- **装填中の色と次弾の色は同じになりにくく**なっています(`PP.PICK_REPEAT`)。
  抽選は毎回独立なので放置すると 4色で 1/4 は同色になり、手札が実質1色に潰れます
  (実測: 277発で連続25%・最長4連続 → 修正後 7%・最長3連続)。
- 装填中の色が**盤面から消えてしまったら自動で引き直し**ます(同ジャンルの定番仕様)。
- 玉が消えると、ときどき**宝やパワーアップが落下**します。**大砲を横に動かしてキャッチ**しましょう。
- 先頭が樽に届いても即死ではありません。**玉2個ぶんまでは飲み込まれても耐えられ**、押し戻せば復帰します。3個目が飲まれると**ゲームオーバー**。
- 原作 Arcade モード準拠: **生存ゲージ(秒数バー)が空になるまで耐える** → そこから**掃討フェーズ**。
  補給が止まるので、**レール上の玉を全部消し切ればレベルクリア**です(+1000)。

### チェーンの動き方

- 押しているのは補給口だけなので、**動くのは最後尾のグループだけ**です。
  列が分断されたら、**前の列は完全に停止**して後ろの列が追いつくのを待ちます(速度は変わりません)。
- 速度は**レール上の位置**で決まります。洞窟から出た直後は速く、**樽に近づくほど少しずつ減速**します。
  基準にするのは**そのグループの先頭**の位置なので、列が長くなっても速くはなりません。
  レベル開始時だけは全体がなだれ込み、1〜2秒かけて通常速度に落ち着きます。
- チェーンが分断されると、後ろに残った断片は**自分の先頭の位置に応じた速度へ乗り換え**ます。
  ただし乗り換えは**約0.45秒待ってから、ゆっくり**(急にガクンと加速しないように)。
  反動で押し戻されている間は基準を据え置くので、弾き飛ばしたご褒美が加速で帳消しになりません。

### 波と宝玉のルール

- 波の補給が終わると、その波の**末尾に宝玉**が付きます。宝玉も列の一員として押し合い・磁力で動きます。
- **一定秒数ごと**(レベル1でおよそ10秒、レベルが上がるほど短く)に**次の波が洞窟から補給**されます。
- 宝玉を連れているグループは**自力で前進**します(後続の波が湧いても置いてけぼりになりません)。
- 宝玉が**1個だけ取り残された(宝単体)**ときは前進をやめ、**磁石**になります。
  色に関係なく**前(樽側)のチェーンを引き戻して**自分に合流させるので、宝を守るほど
  チェーンが樽から遠ざかります。合流後は宝玉を連れたグループとして再び前進します。
- それ以外では、宝玉が**別のグループを引き寄せることはしません**。古い波の宝玉が、分断された
  新しいチェーンの「宝のない側」を引きずってしまい、止まらなくなるためです。
- **宝玉より前(樽側)の玉を、ひとつ前の宝玉まで消し切る**と、宝玉が**解放されて落下** → 大砲でキャッチすると **+500**。
  前の波の宝玉が砕けて列が合体していれば、合体した列を丸ごと消し切るまで解放されません(見えている列がそのまま「担当」)。
- 消し切れないまま**後続の波が接触すると、宝玉は砕け散り**ます。

## パワーアップ / 宝(大砲でキャッチ)

| アイテム | 効果 |
|---|---|
| 🪙 コイン | 集めるとライフ回復に使える(【課題5】、`js/powerups.js` 参照) |
| 🐌 凪の鎖 | チェーンの速度が半分になる(8秒) |
| 🌬️ 引き潮 | チェーン全体が後退する(最大5秒/玉15個ぶん戻したら凪を挟んで前進再開) |
| ⚓ 海神の錨 | チェーンが停止する(5秒) |
| 🎨 カラーボム | **アイテムと同じ色の玉がすべて消える**(キャッチした瞬間に発動) |
| 🔭 羅針の眼 | 着弾点までの長い照準ガイドを表示(10秒) |

- ドロップ率は基本 14%。コンボ中はさらに上がります(道具で盤面が片付くと腕の出番が減るので抑えめ)。
- **カラーボムは色付きで落ちてきます。** 色はドロップした時点で盤面にある色から選ばれ、
  アイテムの玉がその色に塗られています。キャッチした瞬間、その色の玉が全レーンから消えます。
- 時間制の効果は HUD にアイコンと残り秒数が表示されます。

## ルール / スコアデザイン

| 要素 | 内容 |
|---|---|
| 消える条件 | 同色 3 個以上が接触 |
| 基本スコア | n 個消し = **n × 10 点 × コンボ倍率** |
| コンボ | 1.6 秒以内に連続で消えると ×2, ×3, … と倍率アップ |
| 磁力巻き戻し | 消えた隙間の前後が同色なら前の列が後退して合流 → 連鎖の主要な発生源(間に宝玉がいる場合は働かない。ただし宝単体は色に関係なく前の列を引き戻す) |
| 衝突の不応期 | ぶつかった2玉は `PP.BOUNCE_COOLDOWN` 秒だけ磁力の対象から外れる。入れないと「衝突 → 反動で隙間が開く → 同色なので磁力がまた閉じる → 二度目の衝突」で同じ場所がトン、トンと跳ねる |
| 宝キャッチ | 落下アイテムを大砲で拾うとスコア/パワーアップ。解放宝玉は +500 |
| レベルクリア | **生存ゲージ(40 + レベル×10 秒、上限 90 秒)が空になるまで生き残る**(+1000) |
| ゲームオーバー | チェーン先頭が穴に到達 → 4段構成の演出へ(下記) |

## 危機の演出(樽に呑まれかけているとき)

レール全長の **90% 地点**(`PP.CRISIS.start`)から発動します。すべてが**ひとつの心拍に同期**し、
樽に近いほど速く打ちます。

- `SE/crisis.mp3` をループ再生。深いほど**音量とピッチが上がる**(危険曲の上に警報として重なる)
- 赤い帳が心拍で脈打ち、**内側が縮んで視野が狭まる**(トンネル視)
- **樽の口が心拍に合わせて赤く灯る** = 呑み込む口が呼吸している
- ドクロも同じ心拍で膨らみ、心拍ごとに画面がわずかに揺れる
- **樽そのものが心拍に合わせて呼吸**する(口の中心を軸に伸縮)
- **樽から赤い汚染がレールを遡ってくる**。深いほど遠くまで這い、逃げ場が塗り潰されていく
- 深くなると**心拍のたびに地の底が唸り**、さらに深いと**画面が血を流し始める**
- **玉が1個呑まれるたび**に赤い閃光・強い揺れ・腹に来る低音・「**呑まれた! あと N 個**」の宣告
- 押し戻すと「押し戻した!」と安堵の音。ただし**引き際は入りよりゆっくり**(安心しすぎないように)

## ゲームオーバーの演出

怖さは音を足すのではなく**奪う**ことで作っています。

1. **静止** — BGM がその瞬間にぶつ切りになり、盤面が凍りつく。色が抜け落ち、血の帳が降りて心音だけが残る
2. **吸い込み** — `SE/gameover_球が吸い込まれる_SE.mp3`。玉が加速しながら樽へ流れ込み、樽の口では渦が回る。鼓動が速まる
3. **呑み込み** — 最後の1個が消えた瞬間、渦が閉じて画面が暗黒へ落ちる
4. **暗黒** — 灰が降るなか、闇の奥から巨大なドクロがこちらへ迫る。`BGM/gameover_BGM.mp3` が
   立ち上がり、**最後にドクロが一気に顔面まで飛び込んで**(刺し音+閃光+大きな揺れ)から文字が出る

演出中はクリックを受け付けません(文字が出てからリスタート可)。テンポは `PP.OVER`(config.js)で調整できます。

## レベル進行

- 画面は **1000×700**。コースは**7段の蛇行で全長 約6570px(玉 約205個ぶん)**。
  放置すると先頭が樽に届くまで約38秒かかります。
  段間は 80px しかないので、上の段を狙うときは手前の段に当たらない列を探す必要があります。
- レベルが上がると: 生存秒数が延びる / チェーンの進行速度が上がる / 波が進むごとに玉数が増える / **レベル3から色数が 5 → 6 色**に(`PP.COLORS`)。

### 「消えすぎ」を決める2つの変数

撃った玉が消えるかどうかは、実測すると**装填色の重み付けではほとんど動きません**(消せない色を配られたらプレイヤーがペアを作る → 次はそれが消せる、というループになるため、1発で消せる率は 55〜60% で固定)。
効くのは次の2つで、どちらも**「装填色が先頭の危機に噛み合う率」**と**「列がどれだけ伸びるか」**を動かします。

| 設定 | 先頭に効く弾 | 150手後の列 |
|---|---|---|
| 4色 / 塊率0.38(旧・初期値) | 98% | 3個 |
| 5色 / 塊率0.38(旧・Lv3以降) | 95% | 4個 |
| **5色 / 塊率0.15(現・Lv1-2)** | **82%** | **31個** |
| **6色 / 塊率0.15(現・Lv3以降)** | **74%** | **44個** |

- `PP.SPAWN_CLUSTER` … 補給が同色を続ける確率。高いと洞窟から出た時点で並んでおり、1発足すだけで消えます
- `PP.COLORS` … 色数。多いほど装填色が手前の危機に噛み合わなくなります
- レベル開始時は高速で玉がなだれ込み(ロールアウト)、レール 40% 地点で通常速度に落ち着きます。ゲージはロールアウト後から減り始めます。

## ビジュアル

- 玉は**木の砲弾**: 染色した木の下地+中心をずらした年輪+節を「回転レイヤー」に描き、レール上の移動距離に応じて回転させる。陰影とハイライトは固定光源として上に重ねるので、**転がっている**ように見える。
- 背景は**船の甲板**: 板材の色ゆらぎ・うねる木目・継ぎ目・釘をプロシージャルに描画し、暖色の光と周辺減光(ビネット)で臨場感を出す。レールは甲板に彫られた溝として、木の縁 → 深い溝 → 底の影の多重ストロークで表現。

## デザイン意図

- **ゲージ = 緊張感**: 生き残り時間が明示されることで「あと何秒耐えれば…」という原作 Arcade モードの緊迫感を再現。
- **宝玉 = 攻めの動機**: 守っているだけでは宝が砕ける。波を消し切る攻めのプレイに +500 の報酬を出す。
- **距離 = 体力**: チェーンの位置そのものが残り時間。消すと前線が下がり、撃ち損じると押し込まれる、一目で分かる緊張感。
- **横移動の大砲**: 「どの列の下に立つか」というポジショニングの駆け引きが生まれる。落下アイテムのキャッチと射撃位置の取り合いがジレンマになる。
- **巻き戻しが上手さの報酬**: 狙って隙間の色を揃えると、連鎖で前線が大きく後退+コンボ点。運ではなく狙いで起こせる。
- **交換**: 「今の色が使えない」事故を減らし、先読みの計画性を足すための保険。

## コースを自作する

コースは「制御点(`ctrl`)の並び」+少しの見た目フラグだけのデータで、`rail.build` が
それをレールへ変換します。自作するための入口が2つあります。

### ① ビジュアルエディタ(マウスで描く)

- 開き方: 画面下の **🛠 コース作成** ボタン、**E キー**、または `index.html?editcourse=1`
- 操作: **クリックで制御点を追加 / ドラッグで移動 / 右クリックで削除**
- パネル: 直角の道・立体交差・グリッド吸着の切替、角丸調整、組み込みコースの複製、
  **▶ 試遊 / 💾 保存 / 📂 読込 / ⤵ JSON書出 / ⤴ 取込 / 🔗 URL共有**
- 下部に「点数 / 全長 / 検証結果(✅⚠⛔)」がリアルタイム表示されます。

### ② プログラム API(`PP.courseAPI`)

コンソールや自作スクリプトから直接:

```js
var c = PP.courseAPI.create({
  name: "私の航路",
  sharp: false,      // true=直角の街路(角丸) / false=滑らかな曲線
  corner: 24,        // sharp のときの角丸半径
  overpass: false,   // true=自己交差を立体交差(橋)として描く
  ctrl: [ [1400,90], [200,90], [200,300], [1100,300], [1100,520], [150,520] ]
});

c.validate();   // → { ok, errors, warnings, length, points }
c.play();       // その場でレベル1として試遊
c.register();   // COURSES に加えてレベル進行で登場させる
c.save("s1");   // ブラウザ(localStorage)へ保存
c.toJSON();     // 文字列で書き出し(共有・バックアップ)

PP.courseAPI.load("s1").play();      // 保存を読み出して試遊
PP.courseAPI.slots();                // 保存済みスロット名の一覧
PP.courseAPI.fromJSON(json).play();  // もらった JSON をそのまま試遊
PP.courseAPI.resume();               // 通常のコース進行へ戻す
```

- **検証**: 制御点が少なすぎる/座標が数値でない/全長が短すぎる(即死コース)を
  エラーにし、画面外にはみ出す点や未指定の交差は警告で教えます。
- **共有**: `index.html?course=<文字列>`(エディタの「🔗 URL」で生成)で開くと、
  そのコースを直接試遊できます。

制御点の目安: 縦は HUD 下端(50)〜砲口(596)、横は画面内(40〜1260)。最初と最後の点は
洞窟(始点)と樽(終点)なので、画面外へ出しても構いません。

各ファイルは IIFE で閉じ、`window.PP` 名前空間に機能を追加します。共有状態(チェーン・スコア・エフェクト等)は `PP.game` に集約しています。ES Modules を使わないのは、`file://` で index.html を開くだけで動く手軽さを保つためです。

`npm run smoke` はインストール済み Chromium 系ブラウザで `file://` 起動まで確認します。

## 実装メモ

- レールは Catmull-Rom スプラインの制御点列 → 密にサンプリングして**弧長テーブル**化。各玉は「レール上の距離 d」だけを持ち、描画時に座標へ変換。
  コースは右上の洞窟から**7段の蛇行**(段間 80px・半径 40px の半円ターン)で**左下**の樽へ。全長 約 6570px = 玉 205 個ぶん。縦は HUD の下端(44)〜砲口の先(596)しか使えないので、段を増やすぶんは段間を詰め、横は半円の膨らみを抑えて左右へ広げて稼いでいる。洞窟(d=0)は画面右外の x=1150 にあり、玉は画面外から流れ込む。大砲は真上撃ちなので、どの段も水平に保って狙えるようにしてある。
- チェーンは「接触している玉のグループ」単位で更新: 最後尾グループだけが補給に押されて前進、隙間は同色なら磁力後退で閉じる。重なりは後ろ→前への押し出しで解決。
- 発射玉は真上へ直線飛行 → 最近接のチェーン玉に命中したら、レール接線との内積で前/後どちらに割り込むか決定。
- パワーアップの時間効果は `PP.game.effects` の残り秒数で管理し、チェーン更新と照準描画が毎フレーム参照する。
